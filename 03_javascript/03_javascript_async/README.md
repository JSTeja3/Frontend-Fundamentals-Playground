## Phase 10 — Async JavaScript

### Project: API Data Viewer

Built a simple API Data Viewer using JavaScript and JSONPlaceholder.

### Concepts Practiced
- Promises and `.then()`
- Fetch API and JSON parsing
- `async` / `await`
- Error handling with `try` / `catch`
- `finally` for cleanup
- HTTP response validation using `response.ok` and `response.status`
- Loading messages and button disabling
- Displaying API data dynamically using DOM manipulation and template literals

### Features
- Fetches user details from an API
- Displays the user's name, email, and city
- Shows loading and error messages
- Prevents repeated clicks while a request is in progress
- Re-enables the button after success or failure

### Technologies
- HTML
- CSS
- JavaScript
- Fetch API
- JSONPlaceholder

### Notes
This project uses a public test API. It does not include a custom backend or database.

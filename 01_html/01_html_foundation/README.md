# HTML Foundation

A simple webpage built using only HTML to practice fundamental HTML concepts and semantic page structure.

## Concepts Practiced

### Document Structure

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<meta>`
- `<title>`
- `<body>`

### Semantic Elements

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`
- `<address>`

### Content Elements

- Headings: `<h1>` to `<h4>`
- Paragraphs: `<p>`
- Links: `<a>`
- Images: `<img>`
- Ordered lists: `<ol>`
- Unordered lists: `<ul>`
- List items: `<li>`

### Tables

- `<table>`
- `<thead>`
- `<tbody>`
- `<tr>`
- `<th>`
- `<td>`

### Forms

- `<form>`
- `<label>`
- `<input>`
- `<select>`
- `<option>`
- `<textarea>`
- `<button>`

### Input Types Practiced

- `text`
- `email`
- `password`
- `date`
- `radio`
- `checkbox`

## Key Learnings

- HTML provides the structure and meaning of a webpage.
- Semantic elements describe the purpose of different parts of a page.
- Heading levels should represent document hierarchy.
- `id` can uniquely identify an element and can be used for in-page navigation.
- `<label>` can be associated with a form control using the `for` attribute and the input's `id`.
- Inputs with the same `name` can belong to the same group, such as radio buttons.
- The `name` attribute identifies form fields when form data is submitted.
- Tables should be used for tabular data, not page layout.
- The `alt` attribute provides alternative text for images.
